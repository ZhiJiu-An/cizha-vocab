# Tauri App 图标修改手册（macOS）

> 词札项目实测验证 6 次迭代后收敛的最终方案。别再踩 qlmanage 的白边坑了。

---

## 一、你只需要给我什么

**一张 SVG 源文件**，放到 `src-tauri/icons/cizha-icon.svg`。

其他都不用管——我来处理圆角、透明四角、缩放、生成多平台格式。

**SVG 要求**：
- viewBox 建议 `0 0 512 512`（方便 PIL 直接画）
- 不要自己画圆角！圆角由 PIL 统一裁
- 内容填满方形，后续我再缩

---

## 二、最终标准流程（6 次迭代收敛出来的）

```
你: 放好新 SVG → "帮我换图标"
我:

Step 1  PIL 直接画（放弃 SVG → qlmanage 路线）
        ├─ 画完所有元素（纸底渐变 / 墨绿卡 / 文字 / 书签）
        ├─ ⭐ 圆角 mask: ImageDraw.rounded_rectangle(radius=77, L)
        │   → 圆角外 alpha=0（真·透明）
        ├─ ⭐ 整体缩 85% → 居中 paste 到新 512x512 透明画布
        │   → 四周 38px 透明 padding（和 Obsidian/ChatGPT 视觉对齐）
        └─ 输出 icon.png（512x512, RGBA, 四角 alpha=0）

Step 2  从这张 PNG 生成所有 Tauri 格式
        ├─ resize → 32x32.png
        ├─ resize → 128x128.png
        ├─ resize → 128x128@2x.png（256x256）
        ├─ iconutil → icon.icns（10 种尺寸）
        └─ PIL ICO → icon.ico（6 种尺寸）

Step 3  rebuild + 安装
        ├─ cargo tauri build --bundles app
        ├─ rm -rf /Applications/词札.app
        └─ cp -R .app /Applications/

Step 4  你手动
        └─ killall Dock && killall Finder（清 Dock 图标缓存）
```

## 三、关键参数表

| 参数 | 值 | 来源 |
|---|---|---|
| **最终画布** | 512 × 512 RGBA | Apple HIG |
| **圆角半径** | 77px（15%） | Apple HIG + 对比 Obsidian/ChatGPT/Easydict |
| **内容缩放** | 85%（435 × 435） | 实测 85% = 和周围 App 视觉一致 |
| **四周 padding** | 38px 透明 | (512-435)/2 |
| **四角 alpha** | 0（真·透明） | qlmanage 会填白，PIL mask 才对 |
| **生成工具** | 全 Python PIL | 绕开 qlmanage / 绕开 rsvg-convert 安装 |

## 四、避坑清单（6 次迭代踩的）

| 坑 | 现象 | 为什么错 | 正确做法 |
|---|---|---|---|
| qlmanage SVG→PNG | 圆角外填白，alpha=255 | macOS Quick Look 缩略图不保留 alpha | **全用 PIL，不用 qlmanage** |
| SVG 自己画 rx 圆角 | 还是被 qlmanage 填白 | SVG 圆角信息没正确传给 qlmanage | SVG 不画圆角，PIL mask 统一裁 |
| 指望 macOS Dock 自动加圆角 | 方角图标 | Dock **不会**自动加圆角！每个 App 自己画 | PNG 必须自带圆角 |
| 内容填满方形 | 比周围 App 大一圈 | Obsidian/ChatGPT 都有 15% padding | 画完整体缩 85% 居中 |
| PIL 生成 icns 后丢 alpha | 圆角又变白 | iconutil 可能把透明填黑 | icns 从已验证 alpha 的 PNG 生成 |

## 五、图标尺寸一览

Tauri 需要的所有格式（`tauri.conf.json` icon 数组）：

```
src-tauri/icons/
├── cizha-icon.svg      ← 你放的源文件
├── icon.png            ← 512x512 RGBA 四角透明（PIL 生成）
├── 32x32.png           ← 菜单栏/小图标
├── 128x128.png         ← Finder / Launchpad
├── 128x128@2x.png      ← Retina（实际 256x256）
├── icon.icns           ← macOS（含 16-1024 共 10 种尺寸）
└── icon.ico            ← Windows（含 16-256 共 6 种尺寸）
```

## 七、PIL 画圆角图标代码模板（直接复制改元素）

```python
from PIL import Image, ImageDraw

SIZE = 512
img = Image.new("RGBA", (SIZE, SIZE), (0, 0, 0, 0))
d = ImageDraw.Draw(img)

# === 1. 画你的图标元素 ===
# 渐变底
# 卡片（圆角矩形 mask）
# 文字/图形

# === 2. 统一圆角 mask ===
RADIUS = int(SIZE * 0.15)  # 77px
mask = Image.new("L", (SIZE, SIZE), 0)
ImageDraw.Draw(mask).rounded_rectangle(
    [0, 0, SIZE - 1, SIZE - 1], radius=RADIUS, fill=255)
img.putalpha(mask)

# === 3. 整体缩 85% + 居中 ===
SCALE = 0.85
new = int(SIZE * SCALE)
scaled = img.resize((new, new), Image.LANCZOS)
final = Image.new("RGBA", (SIZE, SIZE), (0, 0, 0, 0))
final.paste(scaled, ((SIZE - new) // 2, (SIZE - new) // 2), scaled)

final.save("icon.png")
```
