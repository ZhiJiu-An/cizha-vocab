# v0.7 图片取词功能实现计划

## Context

v0.4/v0.5/v0.6 已打通「词典 + 词库 + 记忆 + 统计」。本期落地原 P2 的 F2-2，但范围经讨论后**三次收窄并最终定型**：

- ❌ 不做系统级快捷键截图取词（网页版无法监听全局热键 / 无法截屏）
- ❌ 不借鉴 Easydict 的 macOS Vision + ScreenCaptureKit 方案（macOS 独占，与「多端可用」目标冲突）
- ✅ **最终形态：搜索页上传图片 → 自动识别图中单词 / 短语 → 点击候选词填入搜索框并自动触发双栏查询**

**用户已确认的决策**：
- 识别引擎：**视觉大模型直出**（不上本地 OCR，零本地依赖、跨平台无限制）
- 点击候选术语：**自动填入搜索框并立即查询**（复用 `doSearch()`）

**前置条件（重要，需用户侧配置）**：当前 `backend/.env` 用的是 DeepSeek 官方端点（`https://api.deepseek.com` / `deepseek-chat`），**官方 API 无视觉模型**。故配置设计为支持独立视觉端点，需用户补一个视觉服务（如阿里云百炼 `qwen-vl-max`、智谱 `glm-4v`，或 OpenRouter 等任意 OpenAI 兼容端点）：

| 环境变量 | 必填 | 说明 |
|----------|------|------|
| `LLM_VISION_MODEL` | ✅ | 视觉模型名；**未配置时接口返回明确提示，功能不崩** |
| `LLM_VISION_BASE_URL` | 可选 | 缺省回落到 `LLM_BASE_URL` |
| `LLM_VISION_API_KEY` | 可选 | 缺省回落到 `LLM_API_KEY` |

沿用 v0.4 定的「配置全部走环境变量、代码不硬编码 Key」约定；`main.py` 已 `load_dotenv("backend/.env")`，加变量后重启即生效。

**版本管理**：数据模型零变更，功能结构变更 → 升 **v0.7**；先把当前 `MVP.md` 归档为 `docs/versions/MVP-v0.6.md`，再改主文件。

## 1. 后端：新建 `backend/app/routes/ocr.py`（前缀 `/api/ocr`）

| 路径 | 方法 | 说明 |
|------|------|------|
| `/extract` | POST | multipart 上传图片 → 视觉模型识别 → 返回候选术语列表 |

**入参校验**：`file: UploadFile = File(...)`（参考 [words.py](file:///Users/azj/Documents/Project/Python_Project/DanCiJi/backend/app/routes/words.py) 的 `batch_import` 写法）；限 `image/*`（png/jpeg/webp/gif/bmp），大小上限 10MB，超限返回 400 明确提示。

**配置读取** `_vision_config()`（照搬 [translate.py](file:///Users/azj/Documents/Project/Python_Project/DanCiJi/backend/app/routes/translate.py) 的 `_llm_config()` 风格 L29-36）：base/key 用上述回落逻辑，model 取 `LLM_VISION_MODEL`；model 缺失时返回 400「未配置视觉模型：请设置 LLM_VISION_MODEL（可选 LLM_VISION_BASE_URL / LLM_VISION_API_KEY）后重启服务」。

**调用上游**：OpenAI 兼容多模态 payload（图片转 base64 data URL，不落盘）：

```python
{"model": model, "temperature": 0.1, "messages": [{"role": "user", "content": [
    {"type": "text", "text": PROMPT},
    {"type": "image_url", "image_url": {"url": f"data:{mime};base64,{b64}"}},
]}]}
```

非流式（`httpx.AsyncClient(timeout=60)`，一次拿全）。

**PROMPT**（要求只出 JSON，便于解析）：

```
请从这张图片中提取出与计算机 / 人工智能 / 大模型领域相关的英文单词或短语。
要求：
1. 只提取专业术语、技术名词或领域常见表达，忽略普通词汇、人名、页码等无关文字
2. 保留图片中的原始拼写，明显识别错误可纠正
3. 去重后按重要程度排序，最多 15 条
4. 只输出 JSON 数组，不要任何解释文字或代码块标记
格式：[{"word": "retrieval-augmented generation", "zh": "检索增强生成"}]
```

**响应解析**：去掉可能的 ```json 围栏 → `json.loads` → 校验为 list[dict] → 字段清洗（word 非空、zh 可空）→ 截断 15 条 → 按 word 小写去重。

**`in_library` 标记**：把识别词与 `words.abbreviation`（小写）比对，命中标注 `in_library=True`，前端标灰显示「已收藏」，避免重复查询。

**异常兜底**（沿用 dictionary.py 的 502 约定）：`httpx.HTTPError` → 502「视觉模型服务连接失败/超时」；非 200 → 502 带上游状态码与截断 body；JSON 解析失败 → 502「模型返回内容无法解析」；统一不泄漏为 500。

**响应模型**（加进 [schemas.py](file:///Users/azj/Documents/Project/Python_Project/DanCiJi/backend/app/schemas.py)）：

```python
class OcrWordItem(BaseModel):
    word: str
    zh: str = ""
    in_library: bool = False

class OcrExtractResponse(BaseModel):
    total: int
    words: List[OcrWordItem]
```

**注册**：[main.py](file:///Users/azj/Documents/Project/Python_Project/DanCiJi/backend/app/main.py) 导入并 `include_router(ocr.router)`，版本号 0.6.0 → 0.7.0（L43、L64 两处）。
