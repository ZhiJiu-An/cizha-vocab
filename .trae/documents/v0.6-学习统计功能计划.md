## 1. 后端：新建 `backend/app/routes/stats.py`（前缀 `/api/stats`）

| 路径 | 方法 | 返回 |
|------|------|------|
| `/summary` | GET | 一次返回全部统计数据（见下） |

**返回结构**：

```json
{
  "totals": {
    "total_words": 4,        // words 总数
    "week_new": 0,           // 近 7 天新增（created_at >= 7天前00:00）
    "total_reviews": 0,      // ReviewLog 总打卡次数
    "reviewed_today": 0      // 今日已复习（distinct word_id，防虚增）
  },
  "tag_distribution": [ {"name": "大模型", "count": 3} ],   // Top 8 标签
  "daily_trend": [ {"date": "10-13", "new_words": 0, "reviews": 0} ],  // 近 7 天完整序列
  "stage_distribution": [ {"stage": 0, "days": 1, "count": 4} ]  // 档位 0~5 分布
}
```

**实现要点**：
- `reviewed_today` 复用 review.py 的 distinct word_id 模式
- `tag_distribution` 复用 words.py `list_tags` 的 Python 侧 Counter 聚合逻辑，取前 8
- `daily_trend`：近 7 天（含今天）Python 侧组装完整序列，无数据补 0；reviews 按 `ReviewLog.reviewed_at` 按天计数，new_words 按 `Word.created_at` 按天计数
- `stage_distribution`：`in_review=1` 按 `review_stage` 分组，恒返回 6 档（无词补 0），附带对应间隔天数 [1,2,4,7,15,30]
