## 1. 数据模型（[models.py](file:///Users/azj/Documents/Project/Python_Project/DanCiJi/backend/app/models.py)）

**Word 加 5 列**（不加独立 ReviewState 表，一对一加列最简）：

| 列 | 类型 | 默认 | 说明 |
|----|------|------|------|
| `review_stage` | Integer | 0 | 当前档位 0~5，对应 [1,2,4,7,15,30] 天 |
| `next_review_at` | DateTime 可空，加索引 | — | 存当天 00:00，**按天对齐** |
| `last_reviewed_at` | DateTime 可空 | — | 上次复习时间 |
| `review_count` | Integer | 0 | 累计复习次数 |
| `in_review` | Integer | 1 | 1=在复习队列（为将来移出留口，本期恒 1） |

**新建 ReviewLog 表**（本期就有消费方：概览「今日已复习数」按 distinct word_id 统计防虚增；详情页显示上次复习）：`id / word_id(索引) / reviewed_at(索引) / result(remember|fuzzy|forget) / stage_before / stage_after`

**初始化**：新词条 `next_review_at = 当天 00:00`（新词最陌生，当天即到期，也便于验证）；存量数据迁移时同样置当天。

## 2. SQLite 轻量迁移（[main.py](file:///Users/azj/Documents/Project/Python_Project/DanCiJi/backend/app/main.py)）

库里已有真实数据，不删库。在 `create_all` 之后加 `_migrate()`：
- `PRAGMA table_info(words)` 取已有列，缺列逐条 `ALTER TABLE ADD COLUMN`；`UPDATE words SET next_review_at = date('now') WHERE next_review_at IS NULL` 补存量
- ReviewLog 由 `create_all` 自动建；整个迁移幂等，不引入 alembic

## 3. 后端 API（新建 `backend/app/routes/review.py`，前缀 `/api/review`）

| 路径 | 方法 | 说明 |
|------|------|------|
| `/overview` | GET | `{due_today, reviewed_today, total_in_queue}`；reviewed_today 查 ReviewLog 按天 distinct word_id |
| `/due` | GET | `tag=""&limit=20` → `{total_due, items}`；条件 `in_review=1 AND next_review_at <= 今日 23:59:59`，按到期时间升序 |
| `/{word_id}/answer` | POST | `{result}` → 算档位：`remember→min(stage+1,5)`，`fuzzy→不变`，`forget→0`；`next_review_at = 今天00:00 + STAGES_DAYS[新stage]天`；写 ReviewLog；返回新状态 |
